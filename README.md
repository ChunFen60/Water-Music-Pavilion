# 🎹 Water Music Pavilion

An AI-powered classical piano music analysis platform based on MIDI data, music feature extraction, and intelligent visualization.

---

# 🚀 Features

## 🎵 MIDI Upload Analysis

Upload MIDI files for automatic music feature extraction and analysis.

## 🎼 Composer Similarity Analysis

Analyze similarities between uploaded MIDI music and famous classical composers.

## 🎭 Emotion Recognition

Detect emotional characteristics of piano music based on musical features.

## 🎹 Piano Roll Visualization

Interactive visualization of MIDI notes using Plotly.

## 🤖 AI Music Assistant

DeepSeek-powered AI analysis for musical interpretation and stylistic understanding.

## 📊 Music Feature Analysis

Extract advanced music features including:

* Average Pitch
* Average Duration
* Average Velocity
* Pitch Variance
* Velocity Variance
* Pitch Range
* Note Density
* Tempo
